# 两个小人 · 交接单（给做交互的人）

小人的 3D 造型、表情和基础动作在 `web/js/characters.js`（分支 `ui/characters`）。

**想要的效果**写在 [`FIRST_PERSON.md`](FIRST_PERSON.md)。本文件是小人模块的接口说明，以及接入房间时会用到的尺寸和坐标。

---

## 1. 现在有什么

- `web/js/characters.js`：全局对象 `CoupleChars`。只依赖 three.js r128（全局 `THREE`），**不需要任何模型文件**，全部用几何体拼成。`index.html` 里已经在 `scene.js` 之前引入了它，但还没有任何地方调用它。
- `web/characters-preview.html`：独立的预览页，直接用浏览器打开就能看（构建时会一起同步进 assets，不影响 app 入口；正式发版前可以从 assets 里排除）。可以切换心情和动作，还能"从某个人的眼睛看出去"。这个页面里的第一人称写法可以直接参考。

| | 唐小轩（`who: 0`） | 宛如（`who: 1`） |
|---|---|---|
| 造型 | 深棕短发，头顶一根呆毛；橙色连帽卫衣带口袋和帽绳；牛仔裤，白球鞋 | 栗色长发加刘海，左边别一个小兔子发夹；浅蓝 A 字裙，白色花瓣领，红色小蝴蝶结；白袜，玛丽珍鞋 |
| 对应房间里的 | 橙色、书桌台灯、小熊玩偶 | 蓝色、落地灯、小兔玩偶 |

画风是 toon 三阶明暗，加一圈描边（用的是反向外壳）。表情是贴在脸上的画布贴图，会自动眨眼。

---

## 2. 接口

```js
const me = CoupleChars.create(THREE, { who: 0 });   // 0 = 唐小轩，1 = 宛如
scene.add(me.group);
// 每一帧调用：
me.update(dt);   // dt 单位是秒
```

**create 的选项**（都可以不填）：

| 选项 | 默认 | 说明 |
|---|---|---|
| `who` | 0 | 0 或 1 |
| `scale` | 1 | 整体缩放 |
| `toon` | true | 关掉后改用 MeshStandardMaterial |
| `outline` | true | 描边；性能吃紧时可以关掉 |
| `outlineColor` | `#4A3A48` | |
| `colors` | | 覆盖配色：`{ skin, hair, top, trim, bottom, shoes }` |

**返回的对象**：

| 成员 | 说明 |
|---|---|
| `group` | `THREE.Group`。原点在两脚中间的地面上，**面朝 +z**。移动时改 `group.position`，转身时改 `group.rotation.y`；朝向某个方向可以用 `Math.atan2(dx, dz)` 算。 |
| `update(dt)` | 每帧调用，驱动动作和眨眼 |
| `setMood(m)` | `neutral` / `happy` / `miss` / `sleepy` / `angry` / `sad` / `hungry`。后六个和 app 里玩偶的心情（`state.moods[w]`）完全一样，可以直接传 |
| `setMotion(m)` | 持续动作：`idle` / `walk` / `sit` |
| `play(name)` | 一次性动作：`wave`（挥手）/ `jump`（跳一下）/ `nod`（点头），播完回到当前的持续动作 |
| `setHeadYaw(rad)` | 只转头，范围 ±0.9，正值是转向小人自己的左边 |
| `getEyeWorldPosition(v3?)` | 两眼中间的世界坐标，第一人称相机放在这里 |
| `info` | `{ height: 1.84, eyeHeight: 1.36, hipHeight: 0.42, seatOffset: 0.4, radius: 0.34 }`，已经乘过 scale |
| `name`、`who`、`moods` | |
| `dispose()` | 从场景移除并释放资源 |

## 3. 和房间的尺寸关系（坐标都来自 `web/js/scene.js`）

- **房间**：地面是 x、z ∈ [-5, 5]，墙在 x = -5 和 z = -5，天花板高 5.2。相机默认只从 +x、+z 方向看进来。
- **小人身高**：约 1.84（算上呆毛约 2.0），眼睛高 1.36。书桌面高 1.5，大约到小人胸口；照片墙在 y 2.6–3.8，小人需要微微抬头看。这个比例是有意设计的：小人视角下，家具显得大一点，更有"走进小屋"的感觉。如果你觉得比例不对，调 `scale`（例如 1.15）比改房间更省事。
- **坐沙发**：沙发坐垫顶面 y ≈ 0.76。坐下时：
  ```js
  c.setMotion('sit');
  c.group.position.y = 0.76 - c.info.seatOffset;
  ```
  沙发靠在左墙，小人坐下后面朝 +x，`rotation.y = Math.PI / 2`。沙发中心是 (-4.25, -0.25)，两个位置可以用 z = -0.85 和 z = 0.35，x 约 -4.0。
- **碰撞**：可以用下面这些地面上的近似矩形或圆（x, z），小人半径按 `info.radius`：

| 物件 | 范围 |
|---|---|
| 可走区域 | x, z ∈ [-4.6, 4.6] |
| 书架 | x [-4.9, -3.4]，z [-5, -4.49] |
| 矮柜和唱片机 | x [-2.8, 0.8]，z [-5, -4.38] |
| 书桌 | x [1.35, 3.95]，z [-4.95, -3.95] |
| 垃圾桶 | 圆心 (1.0, -4.35)，r 0.24 |
| 冰箱 | x [4.05, 4.95]，z [-5, -4.1] |
| 沙发 | x [-4.8, -3.6]，z [-1.8, 1.3] |
| 落地灯 | 圆心 (-4.45, 1.75)，r 0.24 |
| 边桌和信封盒 | 圆心 (-4.4, 2.65)，r 0.38 |
| 小树 | 圆心 (-4.2, 3.85)，r 0.33 |
| 地毯 | 不挡路 |

  墙上的东西（照片墙、软木板、挂历、两扇窗）不挡路，只是要走到跟前才能点。

## 4. 建议的交互做法（供参考，最终由你决定）

1. **谁是"我"**：登录后 `App.state.me` 就是 0 或 1。为两个人各创建一个小人，"我"的那个用第一人称时隐藏（`group.visible = false`），对方的显示出来。预览页的"从眼睛看"就是这么做的。
2. **第一人称相机**：每帧把相机放到 `me.getEyeWorldPosition()`，朝向由拖动屏幕控制的 yaw 和 pitch 决定（pitch 建议限制在 ±60°）。同时把小人的 `group.rotation.y` 设成相机的 yaw，这样对方看到的朝向是对的。
   - 现在 `scene.js` 里的 OrbitControls 有方位角限制（只能从 +x、+z 方向看）。第一人称模式下需要停用它。
   - 也可以保留现在的"俯瞰模式"作为另一个视角，加个按钮切换。
3. **移动**：
   - 手机上用左下角虚拟摇杆，电脑上用 WASD；速度大约 1.6 单位/秒。
   - 移动时调 `setMotion('walk')`，停下来调 `setMotion('idle')`。
   - 撞到第 3 节的碰撞框时沿边滑动。
4. **点房间里的东西**：现在点击用的是从相机发出的射线（`scene.js` 里的 `pick()`），第一人称下照样能用。建议加一个距离限制，比如只有 2.5 以内的东西能点，并在屏幕中心放一个小准星。
5. **让对方看到"我"在哪**：
   - 在 `person` 行的数据里加一个字段，例如 `pos: { x, z, ry, motion, at }`。
   - 要改的地方：`sync.js` 的 `toItems()` 和 `rebuildState()`，以及 `App.state` 里对应的字段。
   - **移动时最多每秒推一次**，停下时再推一次。
   - 对方收到后，在 0.3–0.5 秒内平滑插值过去；收到的 `motion` 为 `walk` 时播放走路动作。
   - 对方离线时（`App.online(w)` 为 false），把他的小人放回沙发上，坐着，用他当时设置的心情。
6. **心情**：小人的表情直接用 `state.moods[w]`。收到 `'mood'` 或 `'all'` 事件时调一次 `setMood`。沙发上原来的玩偶可以保留，也可以去掉，让小人坐在沙发上代替它。
7. **戳一戳**：点对方的小人时，让它 `play('jump')`，再用现有的气泡显示一句话（`scene.js` 里的 `poke()` 和 `App.pokeLine(w)`）。如果想让对方的手机上也看到跳一下，需要通过同步再发一个事件。

## 5. 注意事项

- 小人用的是 **r128 的 API**。如果升级 three.js，至少要改两处：`outputEncoding` / `sRGBEncoding` 在新版本里改名了，`DataTexture` 的格式参数也可能需要调整。
- 每个小人大约有 70 个网格（包括描边），两个一起在手机上没问题。如果低端机卡，先关描边：`outline: false`。
- 脸部贴图是 `CanvasTexture`，切换心情时会重画两张（睁眼和闭眼），不要每帧都调 `setMood`。
- 第一人称下相机贴近墙时可能会穿进墙里。相机的 `near` 设成 0.05 左右，碰撞半径也不要小于 `info.radius`。
- **我验证过的**：两个小人的造型；正面、侧面、背面以及走路、坐下、挥手的姿势（用离线渲染逐帧看过）；预览页脚本能正常解析。
- **没在真机上看过的**：WebView 里的表情贴图和描边效果。打包后请在预览页里每种心情点一遍，确认显示正常。
