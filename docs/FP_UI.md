# 小人视角 · 界面接口（给接交互的人）

小人视角用到的界面元素都已经画好：`web/js/fp-ui.js` 和 `web/css/fp-ui.css`。`index.html` 已经引入了这两个文件，但**还没有挂载**。

这一层**只负责画和发事件**：它不移动相机，不判断碰撞，也不读写数据。这些都由你来接。

可以玩的样例在 `web/fp-ui-preview.html`，直接用浏览器打开。页面底部的 `demo.js` 是一份**演示用的简易接线**（移动、视角、准星射线、对方方位、碰撞），你可以参考，但它不是正式实现：没有同步，碰撞也只是简单地推开。

## 界面上有什么

| 元素 | 位置 | 说明 |
|---|---|---|
| 摇杆 | 左下 | 圆心上写着自己名字的最后一个字，颜色是自己的代表色 |
| 拖动看 | 全屏空白处 | 透明的一层，压在所有按钮下面 |
| 准星 | 屏幕正中 | 对准可以互动的东西时会放大，变成自己的颜色 |
| 目标名 | 准星下方 | 例如"冰箱 · 想一起吃的 / 点一下打开" |
| 互动按钮 | 右下大圆 | 没有目标时是灰的，有目标时变红并有呼吸效果 |
| 表情 | 互动按钮周围 | 挥手 / 跳一下 / 点头，按下后冷却约 1 秒 |
| 视角切换 | 右上 | 小人 / 俯瞰；窄屏上只显示图标 |
| 菜单 | 右上 | 小人视角下原来的底部快捷栏是收起的，点这里展开，点任意一项后会自动收起 |
| 对方方位 | 屏幕边缘 | 对方不在画面里时，用一个头像加箭头指向 TA，并显示距离 |
| 被戳提示 | 顶部 | 一个横条，同时屏幕边缘闪粉色，手机会震一下 |
| 进门动画 | 全屏 | "欢迎回家 + 名字"，然后像圆形遮罩一样打开 |
| 新手引导 | 全屏 | 三处说明，点"知道了"后记住，不再出现 |
| 键盘提示 | 底部中间 | 只在电脑上显示（WASD / 拖动 / E） |

**会自动处理的**：
- 打开面板（`.scrim`）或登录页（`.login`）时，控件自动隐藏，摇杆和按键清零。
- 切到小人视角时，`body` 会加上 `fp-mode`：底部快捷栏收起，左上角的名字卡片变紧凑。
- 系统开了"减少动态效果"时，动画都会关掉。

## 接口

```js
const ui = FPUI.mount({ names: App.state.names, me: App.state.me, view: 'fp' }); // view: 'fp' | 'overview'
```

**你每帧去读：**

| 调用 | 返回 |
|---|---|
| `ui.getMove()` | `{ x, y, active }`。x 向右为正，y 向前为正，范围都是 -1 到 1，摇杆和 WASD 已经合并。俯瞰模式下，或界面被面板挡住时，返回 0。 |
| `ui.getView()` | `'fp'` 或 `'overview'` |

**界面发给你的事件**（`ui.on(name, fn)`，返回一个取消监听的函数）：

| 事件 | 参数 | 建议的处理 |
|---|---|---|
| `look` | `{ dx, dy, pointerType }`，单位像素 | 转头。手机上大约 0.005 弧度/像素，上下限制在 ±60° |
| `tap` | `{ x, y }`，屏幕坐标 | 轻点空白处（没拖动）。用来点对方的小人，或者直接点准星外的物件 |
| `interact` | — | 按了互动按钮或 E 键。只有你之前 `setTarget` 设过目标时才会触发 |
| `emote` | `'wave'`、`'jump'` 或 `'nod'` | 让自己的小人 `play(name)`，并同步给对方 |
| `view` | `'fp'` 或 `'overview'` | 切换相机：停用或启用 OrbitControls，隐藏或显示自己的小人 |
| `menu` | `true` 或 `false` | 菜单展开或收起，一般不用处理 |
| `movestart` / `moveend` | — | 可以用来在停下时推一次位置 |
| `tutorialdone` | — | |

**你告诉界面的：**

| 调用 | 什么时候调 |
|---|---|
| `ui.setTarget({ label, hint? })` 或 `ui.setTarget(null)` | 准星射线在 2.5 以内碰到可互动物件时设，离开时清掉。**只在目标变化时调**，不要每帧调 |
| `ui.setPartner({ visible, angle, distance?, name? })` | 每帧调。`angle` 是对方相对于我视线的方向，单位弧度：0 是正前方，正值在右边。对方在画面里时 `visible: false` |
| `ui.notifyPoke(fromName, line)` | 收到对方戳我的同步事件时调 |
| `ui.playEnter(name)` | 返回 Promise。登录后、镜头飞进小人眼睛的那段时间调用，动画结束后 resolve |
| `ui.showTutorial(force?)` | 第一次进入小人视角时调（会自己记住，只出现一次） |
| `ui.setView(v)` | 用代码切换视角，比如恢复上次的选择。不会触发 `view` 事件 |
| `ui.setMe(w, names?)` | 换账号或者改名字之后调 |
| `ui.setMenuOpen(bool)`、`ui.destroy()` | |

## 接入顺序建议

1. 登录、`App.ready` 之后挂载 FPUI，`view` 用上次保存的值。
2. `ui.playEnter(名字)`，同时让镜头飞到 `me.getEyeWorldPosition()`。动画结束后调 `ui.showTutorial()`。
3. 在每帧循环里：
   - 读 `getMove()`，移动并处理碰撞；
   - 设置相机位置和朝向；
   - 用屏幕中心的射线算出目标，变化时 `setTarget`；
   - 算对方的方位，`setPartner`。
4. 监听 `look`、`tap`、`interact`、`emote`、`view`。
5. 在 `scene.js` 里，小人视角下要停用 OrbitControls，以及现在点击物件的 `pick()`。点击统一改由 FPUI 的 `tap` 和 `interact` 处理，否则会重复触发。
