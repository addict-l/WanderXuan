# 小人视角 · 想要的效果

> 分工：UI 和造型由 Claude 负责（小人模型在 `web/js/characters.js`），交互、同步和落地由 GPT 负责。
> 小人的接口、尺寸和家具碰撞坐标见 [`CHARACTERS.md`](CHARACTERS.md)。

## 一句话

登录以后，我**变成自己的小人走进小屋**：用小人的眼睛看房间，走到照片墙前面看照片，走到书桌前看便利贴；如果对方也在线，就能在房间里看到 TA 的小人走来走去。

## 体验分解

### 1. 进门
- 登录成功后，先显示现在的俯瞰房间，大约 1 秒后，镜头平滑飞到"我"的小人眼睛的位置（全程约 1.2 秒）。
- 我的小人出生在门口附近，大致是房间前方中间的位置，面朝房间里面。

### 2. 第一人称
- 相机放在 `me.getEyeWorldPosition()`。我自己的小人不显示（`group.visible = false`），避免挡住视线。
- 手机竖屏时视角大约 70°，横屏可以更小一点。
- 走路时镜头轻微上下晃动，幅度很小；系统开了"减少动态效果"时关掉。
- 屏幕中心有一个小准星。

### 3. 操作
- **手机**：左下角是虚拟摇杆，用来移动；在屏幕其他地方拖动是转头看（上下最多 ±60°）；点一下就是交互。
- **电脑**：WASD 移动，鼠标拖动看。
- 碰到墙和家具时会沿着边滑过去，不会卡住。家具的碰撞范围见 CHARACTERS.md 第 3 节。

### 4. 和东西互动
- 只有离我 2.5 以内的东西才能点（照片、便利贴、冰箱、书、唱片机、挂历、窗、小树、信封盒、台灯）。
- 准星对准、又在范围内的东西，会微微发亮，并在屏幕下方显示名字，比如"冰箱 · 想一起吃的"。
- 点了以后打开的面板和现在的完全一样，不用改面板。

### 5. 看见对方
- 对方在线时，TA 的小人出现在 TA 当前的位置，走路时播放走路动作，表情就是 TA 设置的心情。
- 对方离线时，TA 的小人坐在沙发上，表情是 TA 最后设置的心情。如果心情是"困了"，可以让 TA 一直闭着眼。
- 两个人距离小于 1.2 的时候，双方的小人都会把头转向对方（`setHeadYaw`）。
- 点对方的小人：TA 跳一下，头顶冒出一句和心情有关的话（沿用现在的 `pokeLine`）。最好**对方手机上也能看到自己被戳了**，比如屏幕边缘闪一下，提示"小轩戳了你一下"。

### 6. 两种视角都保留
- 右上角加一个切换按钮：**小人视角 ↔ 俯瞰**。俯瞰就是现在的样子，方便一眼看全房间。
- 下次打开 app 时，记住上一次用的是哪种视角。

## 同步的要求
- 位置写在 `person` 行的数据里，例如 `pos: { x, z, ry, motion, at }`。**移动时最多每秒写一次**，停下时再写一次。
- 对方收到新位置后，用 0.3 到 0.5 秒平滑插值过去，不要瞬移。
- 改了 `state` 的字段，请在 PR 里写清楚，方便 UI 这边跟进。

## 验收（两台真机）
- [ ] 登录后镜头飞进小人的眼睛，能在房间里走动，撞到家具会停或沿边滑过去，不会穿墙。
- [ ] 走到照片墙前，准星对准一张照片，它会发亮；点开就是照片面板。离得远时点不开。
- [ ] 对方在线时能看到 TA 的小人移动，动作流畅、没有瞬移；对方下线后，TA 的小人会回到沙发上坐着。
- [ ] 两个人走近时会互相转头；戳对方，对方手机上有提示。
- [ ] 视角切换按钮能用，重新打开 app 后保持上次选的视角。
- [ ] 中低端安卓手机上流畅（目标 30 帧以上）；卡的话先关小人的描边（`outline: false`）。
