# 左上角胶囊 · 说明

原来左上角的白色名字卡片太挡视线，已经改成一颗半透明的小胶囊。改动只涉及 UI 文件：`web/js/app.js` 里的 `renderHud` 和 `openSettings`、`web/css/room.css`、`web/css/fp-ui.css`、`web/js/fp-ui.js`。

## 现在的样子

- **胶囊**：`（轩）♥（如） 892 天`。高 44px，用和右上角视角切换按钮一样的磨砂玻璃样式，和它对齐在同一行，两者不会再重叠。
  - 自己的头像外面有一圈自己颜色的描边，代替原来的"我是 宛如"。
  - 对方在线时，对方头像右下角有一个绿点（用的是 `App.online(w)`）。
- **点胶囊**：向下展开一张小卡片，内容是名字、在一起第几天（从哪天开始）、下一个纪念日、对方在线或者上次什么时候来过，还有一个"打开挂历"的链接。6 秒后自动收起，点卡片以外的地方也会收起。
- **小人视角里走动时**：胶囊变成 35% 透明度，展开的卡片也会收起，停下后恢复。这个由 `FPUI.getMove()` 自动给 `body` 加减 `fp-moving` class 实现，不需要另外接。
- **"时间 实时/白天/黄昏/夜晚"**：挪到了 **设置 → 房间光线**，默认"跟着真实时间"。选择会存在本机的 localStorage（键名 `room-time-mode`）。
- **俯瞰模式的"拖动旋转 · 缩放 · 点房间里的东西"提示**：只在前 3 次打开时显示（localStorage 键名 `room-hint-visits`）。
- **本地预览模式**：切换"我是谁"的按钮在展开的卡片里。

## 给接交互的人

- 不需要接任何新东西，`mountHud()` 和以前一样调用。
- 胶囊会在 `calendar`、`letters`、`who`、`names`、`all`、`presence`、`time` 这些事件时重画。如果你新增了表示在线状态变化的事件，告诉 UI 这边加进去。
- `.hud` 现在只是一个透明的容器，请不要再给它加背景或者内边距。
