# 双人小屋 · 交接单（给接手部署和打包的人）

这是一个给两个人用的 3D "小房间" app：唐小轩和宛如各自在安卓手机上登录，看到同一个房间。照片墙、便利贴、信、冰箱贴、书架等内容实时同步。

**前端和数据同步已经写完并测过。还剩两件事交给你：**

1. 把后端 PocketBase 部署到用户的**阿里云服务器**上；
2. 用 **Android Studio** 把 `web/` 包成 APK 并导出。

用户在中国大陆和海外之间使用，大陆网络对国外服务很差。所以 app 里**不能依赖任何国外 CDN**。现在所有脚本和字体都已经放在 `web/` 里，请保持这一点。

## 3. 任务 A：部署 PocketBase 到阿里云

服务器上需要做的事：

1. **确认 CPU 架构**：运行 `uname -m`。`x86_64` 用 amd64 包，`aarch64` 用 arm64 包。
2. **上传文件**：把 `server/` 整个传到服务器，例如 `/opt/couple-room/`（用 scp，或阿里云 Workbench 的文件上传）。服务器上**不需要访问 GitHub**，二进制包已经带好了，可以用 `SHA256SUMS.txt` 校验。
3. **解压**：
   ```bash
   cd /opt/couple-room && unzip pocketbase/pocketbase_0.40.5_linux_amd64.zip pocketbase -d . && chmod +x pocketbase
   ```
4. **配置 systemd 服务**：
   ```ini
   # /etc/systemd/system/couple-room.service
   [Unit]
   Description=Couple Room (PocketBase)
   After=network.target
   [Service]
   WorkingDirectory=/opt/couple-room
   ExecStart=/opt/couple-room/pocketbase serve --http=0.0.0.0:8090 --dir=/opt/couple-room/pb_data --migrationsDir=/opt/couple-room/pb_migrations
   Restart=always
   [Install]
   WantedBy=multi-user.target
   ```
   然后运行 `systemctl daemon-reload && systemctl enable --now couple-room`。
5. **第一次启动会自动执行迁移**，建好 `items`、`photos` 两个集合，并创建两个账号：
   | 名字 | email | 初始密码 | who |
   |---|---|---|---|
   | 唐小轩 | xiaoxuan@example.com | 123456 | 0 |
   | 宛如 | wanru@example.com | 123456 | 1 |
   
   邮箱只是登录标识，不会发信。两个账号的密码最小长度已经改成 6 位，自助注册已关闭。
6. **开放端口**：在阿里云**安全组**里放行 TCP 8090 入方向；如果系统里开着 firewalld 或 ufw，也要放行。
7. **验证**：从外网访问 `http://<公网IP>:8090/api/health`，应该返回 `{"message":"API is healthy."...}`。
8. **（可选）建管理员**：`./pocketbase superuser upsert <邮箱> <密码>`，之后可以在 `http://<IP>:8090/_/` 打开后台。
9. **备份**：全部数据和照片都在 `/opt/couple-room/pb_data/`，定期备份这个目录即可。

**注意**

- 如果服务器在大陆地域：用 **IP + 8090 端口**直接访问，通常不需要备案。如果以后想用域名加 80/443 端口，就要先做 ICP 备案。
- 现在走的是 **HTTP 明文**，所以 APK 必须允许明文流量（见第 4 节）。以后有备案域名了，可以在前面加 Caddy 或 Nginx 上 HTTPS，再把 `config.js` 里的地址改成 https。
- **不要**改迁移文件名，也不要重复执行迁移。如果需要改表结构，新建一个迁移文件。

## 4. 任务 B：Android Studio 打包 APK

用 Java 或 Kotlin 写一个空 Activity 的 WebView 壳就够了。要求如下，每一条都有原因，请不要省略：

1. **工程路径只能用英文**。用户是 Windows 系统，路径里有中文时 AGP 会报错。
2. **放入前端文件**：把 `web/` 整个复制到 `app/src/main/assets/www/`。
3. **用 `androidx.webkit.WebViewAssetLoader` 加载页面**，地址是
   `https://appassets.androidplatform.net/assets/www/index.html`。
   **不要用 `file:///android_asset/...`**，否则自带字体会因为跨域加载失败，localStorage 的行为也不稳定。
4. **WebView 设置**：
   - `javaScriptEnabled = true`
   - `domStorageEnabled = true`（登录状态和服务器地址存在 localStorage 里）
   - `mixedContentMode = MIXED_CONTENT_ALWAYS_ALLOW`：页面是 https（assets 域名），而 API 是 http://IP:8090，不加这一项会被拦截。
5. **网络**：`AndroidManifest.xml` 里加 `INTERNET` 权限，并在 `<application>` 上设置 `android:usesCleartextTraffic="true"`（或者用 network_security_config 只放行这台服务器的 IP）。
6. **文件选择**：实现 `WebChromeClient.onShowFileChooser`。照片墙、书架用的是 `<input type="file" accept="image/*">`，不实现的话点了没有反应。用 `fileChooserParams.createIntent()` 打开系统选择器，再把结果交回 `filePathCallback`；用户取消时传 `null`。
7. **外部链接**：在 `shouldOverrideUrlLoading` 里，凡是 host 不是 `appassets.androidplatform.net` 的链接（歌单里的网易云、Spotify），一律用 `Intent.ACTION_VIEW` 交给系统浏览器打开，不在 WebView 里打开。
8. **返回键**：调用 `webView.evaluateJavascript("window.__back&&window.__back()", ...)`。返回值为 `"true"` 表示页面已经关掉了一个打开的面板，这时什么也不做；否则执行 `finish()`。
9. **硬件加速**保持默认开启，3D 房间依赖 WebGL。
10. **服务器地址**（二选一）：
    - 打包前把 `web/config.js` 里的 `server` 填成 `'http://<公网IP>:8090'`，登录页就会自动带上这个地址；
    - 或者留空，用户第一次打开时在登录页填写，之后会记住（localStorage 的键名是 `couple-room-server`）。
11. **App 名和图标**：App 名用"双人小屋"；图标用 `icons/` 里的图片（`maskable-512.png` 适合做 adaptive icon 的前景）。
12. **导出**：给两个人自己装的话，用 **Build → Build APK(s)** 导出 debug APK 就可以侧载安装。如果要签名的 release 包，用 **Generate Signed App Bundle / APK**。

依赖只需要 `androidx.webkit:webkit`。也可以用 AppCompat 或 ComponentActivity，用了的话返回键可以改用 `OnBackPressedCallback`。

## 5. 设计说明（维护时用）

- **数据模型**：每样东西对应 `items` 里的一行，字段是 `kind`、`ref`、`data(json)`，`(kind, ref)` 唯一。记录 id 由 `kind/ref` 哈希成 15 位小写字母和数字（见 `sync.js` 里的 `rid()`），两台设备算出来的 id 相同，所以写入时先 update，返回 404 再 create。
  - `kind` 有这些取值：`photo`（ref 是相框槽位 0–7）、`todo`、`event`、`letter`、`eat`、`recipe`、`book`、`song`、`meta`（main）、`person`（0 或 1，含名字、城市、心情、lastSeen）、`checkin`（ref 是 `日期:who`，每人每天一行，避免两人同时打卡时互相覆盖）。
- **同步方式**：本地修改内存里的 `state` 后，比较哪些行和上次服务器的版本不同（JSON 按键排序后比较），只推送有变化的行。对方的改动通过实时订阅到达后，**立刻**合并进 `state`，再延迟统一重绘。同一行两人同时改时，后写的覆盖先写的，对两个人的使用量足够了。
- **照片**：存在 `photos` 集合里（受保护文件），`data.path = "<记录id>/<文件名>"`。下载时先拿 file token，fetch 成 blob 再生成 objectURL；因为是同源的 blob 地址，three.js 用它做贴图不会出现跨域污染的问题。
- **在线状态**：每 60 秒心跳一次，把 lastSeen 写进自己的 `person` 行。对方的 lastSeen 在 3 分钟以内就算在线，在线的一方那边的灯会亮。
- **本地预览模式**：页面里没有加载 `pocketbase.umd.js` 时，自动进入单机预览，数据存在 localStorage，左上角可以切换"我是谁"。

## 6. 验收清单（真机）

用两部手机分别登录唐小轩和宛如，逐项确认：

- [ ] 登录页填服务器地址，输入 123456 能进门；输错密码有提示；关掉 app 再打开，仍保持登录。
- [ ] 3D 房间能拖动旋转、能缩放；点房间里的物件能打开对应面板；返回键能先关掉打开的面板。
- [ ] 照片墙：在空相框里上传照片，能打开系统相册；上传后照片是歪着挂的，对方手机几秒内能看到，对方点"扶正"后，两边都变正。
- [ ] 便利贴：贴给对方后，对方墙上会出现；完成后有纸团飞进垃圾桶的动画。
- [ ] 信封盒：给对方写信后，对方的信封盒里会冒出一个信封角；拆信后信封角消失。
- [ ] 小树：两个人都打卡浇水后，面板上那一天显示两个人都来过。
- [ ] 一部手机退到后台再回来，能看到这段时间对方做的修改。
- [ ] 歌单里的"网易云"链接会跳到系统浏览器。
- [ ] 设置里改密码需要输入旧密码，改完后用新密码可以登录。

## 7. 安全提醒（请转告用户）

- 初始密码 `123456` 太弱，而且现在是 HTTP 明文传输。在同一个网络里的人或者运营商都能看到传输内容，知道 IP 的人也能试着猜密码。建议用户尽快在 app 的**设置 → 改密码**里换掉。如果以后有了备案域名，再加上 HTTPS。
- 阿里云安全组只需要放行 8090。
- PocketBase 管理后台 `/_/` 要设一个强密码的管理员，或者干脆不建管理员。
